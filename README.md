# NamePicker

A small web app for choosing or randomly generating a username and registering it in a list of enrolled users.

## Description

The user can either type their own username or generate one randomly from a predefined list. When saving, the app checks that the field is not empty and that the name isn't already taken. If everything is valid, the name is dynamically added to the "Enrolled Users" list.

## Features

- Generate a random username with a button
- Enter a custom username
- Validation for empty field and duplicate names
- Visual feedback (success/error messages)
- Dynamically updated list of enrolled users

## Technologies

- HTML5
- Tailwind CSS + DaisyUI
- JavaScript (Vanilla)
